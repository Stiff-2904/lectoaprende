⚙️ Para activar la voz infantil Marina

Necesitas configurar una clave de Microsoft Azure Speech en el servidor. Abre el archivo GUIA-VOZ-LITO.md incluido en el proyecto. Nunca pongas la clave en el navegador. Hasta entonces, se utilizará la voz de tu dispositivo.

El audio se reproduce cuando el niño pulsa un botón. La voz infantil utiliza un servicio externo cuando está activado; las instrucciones se envían a Azure, no los datos del niño.

🎧 Escuchar

Use el botón de audio para repetir cada indicación. Acompañe la pronunciación de letras y sílabas.

🌱 Practicar

Permita que el niño intente varias veces. Celebre el esfuerzo, no solo la respuesta correcta.
